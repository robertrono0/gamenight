🌈 Color Clue

Rounds

📜 How to Play

🌈A giant grid of colors fills the TV. Each square has a code, like F7.
🎨One player (the cue giver) secretly gets a color on their phone.
🗣️They say ONE word to describe it (like "banana"). No color names or objects in the room!
📱Everyone else types the square code they think it is, like F7.
🎯Exact = 3, one square away = 2, two away = 1.
🎨The cue giver gets +1 for every guess within one square.
